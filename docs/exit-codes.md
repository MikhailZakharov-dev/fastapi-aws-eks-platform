# Шпаргалка: exit code → где смотреть

Команда возвращает **exit code**: `0` = успех, не-`0` = провал. `$?` хранит код последней.
CI решает «зелёная/красная» по **финальному коду скрипта джобы**.

## Пайпы (главный footgun)

- По умолчанию `a | b | c` возвращает код **последней** (`c`). Провал `a` маскируется → зелёная джоба, битый артефакт.
- `set -o pipefail` → код **последней упавшей** в пайпе (любой провал всплывает).
- Стандарт CI-скрипта: `set -euo pipefail` — `-e` fail-fast, `-u` ошибка на необъявленную переменную, `-o pipefail`.

## Частые коды

| Код | Значение |
| --- | --- |
| 0 | успех |
| 1 | общая ошибка |
| 2 | неверное использование команды |
| 126 | файл не исполняемый |
| 127 | command not found (опечатка / нет в PATH) |
| 128+N | убит сигналом N |
| 130 | Ctrl+C (SIGINT, 128+2) |
| 137 | SIGKILL (128+9) — **OOMKilled** / `docker kill` |
| 143 | SIGTERM (128+15) — graceful stop не успел |

## Где смотреть

- **CI-джоба:** лог — какая команда и с каким кодом упала (с `pipefail` — реальная; без него — маскируется последней).
- **k8s под:** `kubectl logs <pod>` (вывод) · `kubectl describe pod <pod>` (Reason: OOMKilled/Error, Exit Code, Events).
- **docker:** `docker inspect <ctr> --format '{{.State.ExitCode}} {{.State.OOMKilled}}'`.
- **137** → почти всегда память: cgroup-лимит → OOM killer (темы 11/30).
